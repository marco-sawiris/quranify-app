# 📖 Quranify - تطبيق القرآن الكريم والصوتيات الذكي

تطبيق إسلامي حديث ومتكامل مبني باستخدام **React Native / Expo (SDK 52)** و **TypeScript** ومحرك صوتيات مزدوج.

---

## 🌟 المميزات المكتملة

1. **القرآن والتلاوة:**
   - فهرس متكامل لجميع السور الـ 114 مع تصنيف السور (مكية / مدنية) وعدد الآيات.
   - دعم كبار القراء (مشاري العفاسي، عبد الباسط عبد الصمد، سعد الغامدي، ماهر المعيقلي، ياسر الدوسري، محمود الحصري، إسلام صبحي).
   - المشغل المصغر العائم (Mini Player) المستمر في كافة الشاشات.
   - شاشة المشغل الكامل (Full Player) مع القرص الدائري وتتبع الآية النشطة ونظام التفسير.

2. **أصوات الأجواء والخلفيات (Ambient Dual-Audio Engine):**
   - محرك صوتيات مزدوج يتيح تشغيل أصوات الطبيعة في الخلفية بالتزامن مع تلاوة القارئ.
   - يتضمن 7 أصوات أجواء مدمجة: (مطر هادئ، حطب ونار، خرير النهر، طيور الصباح، نسيم الرياح، أمواج البحر، خرخرة قطة).
   - تحكم مستقل بمستوى صوت القارئ ومستوى صوت المؤثر الخلفي، مع إمكانية الإيقاف والتبديل السلس.

3. **قوائم التشغيل والقصص الصوتية:**
   - قوائم مختارة لمختلف الحالات (سكينة ونوم هادئ، بركة الصباح، تركيز في العمل، الرقية والتحصين).
   - قسم خاص بالقصص الصوتية (قصص الأنبياء، أصحاب الكهف، سيرة المرسلين).

4. **البحث الشامل:**
   - بحث سريع وفوري في أسماء السور وأرقامها وقائمة القراء.

5. **الإحصاءات والأهداف:**
   - تتبع الأيام المتتالية (Streak).
   - عداد ومخطط بياني للهدف اليومي بالدقائق.
   - سجل إجمالي ساعات الاستماع والمفضلة.

6. **الإعدادات والتنزيلات:**
   - إدارة التنزيلات والذاكرة المؤقتة (Cache).
   - إعدادات جودة الصوت والتنبيهات.

---

## 🚀 تشغيل التطبيق

### 1. عبر المتصفح (Web Preview):
```bash
npx expo start --web
```

### 2. عبر هاتف أندرويد (تطبيق Expo Go):
```bash
npx expo start
```
ثم امسح رمز الاستجابة السريعة (QR Code) باستخدام تطبيق **Expo Go**.

### 3. بناء ملف APK للتثبيت المباشر:
```bash
npx eas build -p android --profile preview
```
أو عبر Expo Prebuild:
```bash
npx expo run:android
```
